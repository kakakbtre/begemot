# Weather Diary - Консольное приложение для ведения дневника погоды

## Краткое описание программы

**Weather Diary** — это консольное приложение на Python для ведения личного дневника погоды. Программа позволяет пользователям записывать, просматривать, фильтровать и удалять метеорологические данные, а также визуализировать изменения температуры с помощью графиков.

### Основной функционал

- **Добавление записей** о погоде с указанием даты, температуры, типа погоды и количества осадков
- **Просмотр всех записей** в структурированном табличном виде
- **Удаление записей** по конкретной дате
- **Фильтрация записей** по диапазону дат или диапазону температур
- **Визуализация данных** — построение графика температуры по дням с помощью библиотеки matplotlib
- **Автоматическое сохранение** — данные хранятся в JSON-файле и загружаются при запуске

### Технические особенности

- Реализована на **Python 3.7+** с использованием **объектно-ориентированного подхода**
  - **Инкапсуляция**: поля классов защищены (с префиксом `_`)
  - **Наследование**: различные типы погоды (`SunnyWeather`, `RainyWeather`, `CloudyWeather`, `SnowyWeather`) наследуются от базового класса `WeatherType`
- **Валидация ввода** с помощью декоратора и собственных проверок:
  - Проверка формата даты (ГГГГ-ММ-ДД)
  - Проверка температуры (диапазон от -50 до +50°C)
  - Проверка осадков (неотрицательное число)
  - Защита от дублирования записей на одну дату
- Используемые библиотеки: `datetime`, `json`, `matplotlib`, `typing`

## Как запустить приложение

Шаг 1: Установка Python

Убедитесь, что на вашем компьютере установлен Python версии 3.7 или выше:
```bash
python --version

Шаг 2: Установка зависимостей
Установите необходимую библиотеку matplotlib для построения графиков:

bash
pip install matplotlib

Шаг 3: Сохранение программы
Скопируйте код программы в файл с именем weather_diary.py.

Шаг 4: Запуск
Выполните команду в терминале (командной строке):
bash
python weather_diary.py

###Шаг 5: Работа с программой
После запуска вы увидите главное меню. Файл weather_diary.json с данными создастся автоматически в той же папке, где находится программа.
