## 📊 Консольное приложение для работы с графами

**Graph Navigator** - это мощное консольное приложение на Java для создания, визуализации и анализа графов различного типа. Программа реализует ключевые алгоритмы теории графов с использованием объектно-ориентированного подхода и паттернов проектирования.

## ✨ Возможности

- **3 типа графов**: ориентированные, неориентированные и взвешенные
- **Алгоритмы обхода**: BFS (поиск в ширину) и DFS (поиск в глубину)
- **Поиск кратчайших путей**: алгоритм Дейкстры для взвешенных графов, BFS для невзвешенных
- **Сохранение и загрузка**: экспорт/импорт графов в формате JSON
- **Валидация данных**: проверка уникальности вершин и корректности весов
- **ООП дизайн**: инкапсуляция, наследование, полиморфизм
- **Паттерн "Фабрика"**: гибкое создание различных типов графов

## 🚀 Быстрый старт

### Системные требования

- Java 11 или выше
- Maven 3.6+
- Git (для клонирования репозитория)

### Установка и запуск

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/yourusername/graph-navigator.git
cd graph-navigator

2. Создайте необходимые директории

bash
mkdir -p graphs/saved_graphs

3.Соберите проект с помощью Maven

bash
mvn clean compile

4.Запустите приложение

bash
mvn exec:java -Dexec.mainClass="Main"
