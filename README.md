## Краткое описание программы
Expense Chart — это консольное приложение на Python для учёта и анализа личных финансов. Программа позволяет добавлять расходы, распределять их по категориям, фильтровать по датам, сохранять данные в JSON-файл и визуализировать статистику с помощью графиков (круговые и линейные диаграммы).

### Основные возможности:

Добавление, просмотр и удаление расходов.

Категоризация трат (Еда, Транспорт, Развлечения, Покупки и др.).

Поддержка двух специальных типов расходов:

Обязательные расходы (коммунальные платежи, кредиты и т.п.)

Расходы на досуг с оценкой уровня удовольствия (от 1 до 10).

Фильтрация расходов по категории или временному периоду.

Подсчёт суммы расходов за выбранный период с разбивкой по категориям.

Визуализация:

Круговая + столбчатая диаграмма расходов по категориям.

Линейный график тренда расходов по месяцам за выбранный год.

Сохранение и загрузка данных в формате JSON.

Программа построена с использованием принципов ООП (инкапсуляция, наследование, полиморфизм) и разделена на логические слои: модели данных, менеджер, представление (консоль) и контроллер.

### Как запустить приложение
Требования
Python 3.8 или выше

Установленные библиотеки:

matplotlib

numpy

Установка зависимостей
bash
pip install matplotlib numpy
Запуск
Скопируйте код в файл, например expense_chart.py, и выполните команду:

bash
python expense_chart.py

При первом запуске будет создан новый файл данных expenses.json (при сохранении). При последующих запусках данные загружаются автоматически.
